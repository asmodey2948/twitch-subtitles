# Задачи версии 0.2.1 — Переключение моделей STT

## Цель

Дать пользователю возможность выбирать модель Whisper (tiny/base/small/medium/large) через UI без перезапуска сервисов. При смене модели старая выгружается из памяти, новая загружается по требованию.

## Критерий завершения 0.2.1

- GET /models возвращает список моделей и текущую
- PUT /settings переключает модель, невалидная модель → 400
- Frontend: dropdown загружает список моделей, смена модели отправляет PUT
- Запись с микрофоном работает с выбранной моделью
- Все тесты (pytest + dotnet test) проходят
