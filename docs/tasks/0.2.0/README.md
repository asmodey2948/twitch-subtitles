## Критерий завершения 0.2.0

- Frontend: выбор источника (Файл / Микрофон)
- Frontend: перечисление и выбор устройства микрофона
- Frontend: захват аудио с выбранного устройства
- Чанки по 3-5 сек отправляются через WebSocket
- STT + перевод работают в real-time
- Субтитры отображаются по мере готовности
- Latency < 10 сек (включая обработка)
