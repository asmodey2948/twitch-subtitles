# Задача 3: Frontend

## Описание

Создать минимальный веб-интерфейс для загрузки аудиофайла и отображения результатов транскрипции и перевода.

---

## Требования

### Функциональные

- [ ] Форма загрузки аудиофайла (.mp3, .wav)
- [ ] Отображение статуса обработки
- [ ] Вывод русского текста
- [ ] Вывод английского текста
- [ ] Обработка ошибок

### Технические

| Компонент | Технология |
|-----------|------------|
| Framework | Любой (HTML/JS, Razor Pages, React) |
| API | Fetch / XMLHttpRequest |
| Styling | Минимальный CSS |

---

## Шаги реализации

### 3.1: Базовая структура

- [ ] HTML страница с формой загрузки
- [ ] Input type="file" (accept=".mp3,.wav")
- [ ] Кнопка отправки

### 3.2: JavaScript

- [ ] Обработка submit формы
- [ ] FormData с файлом
- [ ] Fetch POST к `/subtitles`
- [ ] Отображение ответа
- [ ] Обработка ошибок

### 3.3: Стилизация

- [ ] Минимальный CSS для читаемости
- [ ] Отображение статуса (loading)
- [ ] Разделение областей для ru/en текста

### 3.4: Тестирование

- [ ] Загрузка тестового файла
- [ ] Проверка отображения результата
- [ ] Проверка обработки ошибок

---

## Критерий готовности

Пользователь может загрузить файл и увидеть оба текста (русский и английский).
