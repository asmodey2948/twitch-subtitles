# Задача 4: Интеграция

## Описание

Объединить все компоненты в работающее приложение, выполнить end-to-end тестирование.

---

## Требования

### Функциональные

- [ ] Оба сервиса запускаются вместе
- [ ] Frontend взаимодействует с Backend
- [ ] Backend взаимодействует с ML Service
- [ ] Полный цикл работает: аудио → субтитры

### Технические

| Аспект | Требование |
|--------|------------|
| Запуск | Оба сервиса стартуют корректно |
| Логирование | Ошибки видны в логах |
| Восстановление | Обработка падения ML сервиса |

---

## Компоненты для интеграции

```
┌──────────────┐
│   Frontend   │
│   (Browser)  │
└──────┬───────┘
       │ HTTP
       ↓
┌──────────────┐
│  C# Backend  │
│  (ASP.NET)   │
└──────┬───────┘
       │ HTTP
       ↓
┌──────────────┐
│ ML Service   │
│  (Python)    │
└──────────────┘
```

---

## Шаги реализации

### 4.1: Настройка окружения

- [ ] Переменные окружения/конфигурация для URL ML сервиса
- [ ] Проверка портов (Backend и ML не конфликтуют)
- [ ] ML модели скачаны/доступны

### 4.2: Запуск сервисов

- [ ] Способ 1: Два терминала (ручной запуск для разработки)
- [ ] Способ 2: Docker compose (опционально)
- [ ] Проверка: оба сервиса отвечают на health check

### 4.3: End-to-end тесты

| Тест | Описание |
|------|----------|
| E2E-1 | Загрузить .mp3 → получить оба текста |
| E2E-2 | Загрузить .wav → получить оба текста |
| E2E-3 | Неверный формат → 400 |
| E2E-4 | ML сервис вниз → 500 |
| E2E-5 | Пустой файл → корректная ошибка |

### 4.4: Документация запуска

- [ ] Инструкция по запуску обоих сервисов
- [ ] Требования к окружению (Python, .NET 8)
- [ ] Известные ограничения

---

## Критерий готовности

Пользователь может открыть приложение, загрузить аудиофайл и получить субтитры без перезапуска сервисов.
