## Критерий завершения 0.2.2

- GET /api/settings возвращает все настройки (model, vad_enabled, chunk_duration_ms, overlap_ms)
- PUT /api/settings обновляет настройки, персистентно сохраняет в JSON
- VAD включается/выключается через чекбокс в UI, состояние синхронизируется с ML-сервисом
- Длина чанка и оверлап настраиваются через UI (1–10 сек, 0–3 сек)
- Overlap buffer корректно добавляет хвост предыдущего чанка к следующему
- Все тесты (pytest + dotnet test) проходят
