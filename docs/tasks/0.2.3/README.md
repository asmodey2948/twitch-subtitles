# Задачи версии 0.2.3 — Дедупликация + багфиксы

## Цель

При включённом оверлапе один и тот же фрагмент речи попадает в два соседних чанка, создавая дубликаты в субтитрах. Нужна дедупликация: удалять из нового субтитра начало, которое уже было в предыдущем.

---

## Алгоритм дедупликации

Реализован в `SubtitlesWebSocketHandler.Deduplicate()` (C#).

### Принцип

1. Разбить предыдущий и текущий текст на слова
2. Нормализовать каждое слово: lowercase + убрать пунктуацию (оставить только буквы и цифры)
3. Найти максимальную последовательность слов с конца предыдущего текста, совпадающую с началом нового
4. Если совпадение ≥ 2 слов — убрать эти слова из начала нового текста
5. Вернуть очищенный текст

### Порог: 2+ слов

При совпадении 1 слова дедупликация не применяется — это скорее всего случайное совпадение, а не overlap. Порог в 2 слова отсеивает ложные срабатывания.

### Нормализация

Whisper может по-разному транскрибировать один и тот же фрагмент: "как дела" vs "Как дела,". Нормализация убирает регистр и пунктуацию перед сравнением. При этом выводится оригинальный текст (без нормализации), убираются только совпавшие слова из начала.

### Пример

```
Предыдущий: "привет как дела"
Новый:      "как дела сегодня"
Нормализованные концы/начала совпадают: ["как", "дела"] (2 слова)
Результат:  "сегодня"
```

### Условия срабатывания

Дедупликация применяется только если:
- В настройках включена `dedup_enabled`
- В настройках `overlap_ms > 0`
- Есть предыдущий субтитр для данного соединения
