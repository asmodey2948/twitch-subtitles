# Запуск Twitch Subtitles

## Требования

| Компонент | Версия |
|-----------|--------|
| Python | 3.10+ |
| .NET SDK | 8.0+ |
| ffmpeg | любой |
| ОЗУ | от 4 ГБ (модели ML загружаются в память) |

## Быстрый старт

```bash
./start.sh
```

Скрипт запустит оба сервиса и откроет браузер. Для остановки — `Ctrl+C` или `./stop.sh`.

## Ручной запуск

### 1. Python ML Service

```bash
cd src/TwitchSubtitles.ML
source .venv/Scripts/activate    # Windows Git Bash
uvicorn main:app --host 127.0.0.1 --port 8000
```

При первом запуске скачаются модели:
- faster-whisper base: ~150 МБ (tiny ~75 МБ, large ~3 ГБ)
- MarianMT ru-en: ~300 МБ

Проверка: http://127.0.0.1:8000/health → `{"status": "ok"}`

### 2. C# Backend

```bash
cd src/TwitchSubtitles.Web
dotnet run --no-https
```

Проверка: http://localhost:5098/ — страница приложения.

**Порядок:** сначала ML Service, затем Backend. Backend обращается к ML Service по адресу из `appsettings.json`.

## Порты

| Сервис | Порт |
|--------|------|
| C# Backend (Frontend + API) | 5098 |
| Python ML Service | 8000 |

## Использование

### Режим файла

1. Откройте http://localhost:5098
2. Выберите «Загрузить файл»
3. Загрузите .mp3 или .wav
4. Получите транскрипцию и перевод

### Режим микрофона (real-time)

1. Выберите источник «Микрофон»
2. Выберите устройство захвата
3. Нажмите «Начать запись»
4. Субтитры появляются в реальном времени

### Настройки

На странице доступны:
- **Модель STT** — tiny / base / small / medium / large (переключение без перезапуска)
- **VAD** — фильтр тишины (Silero VAD через faster-whisper)
- **Дедупликация** — убирает повторы при overlap чанков
- **Длина чанка** — 1–10 сек (сколько аудио накапливается перед распознаванием)
- **Оверлап** — 0–3 сек (перекрытие чанков для контекста)

## Настройка OBS

### Принцип работы

```
Аудио из OBS → виртуальное аудиоустройство → Twitch Subtitles (микрофон)
                                                      ↓
                                               WebSocket /ws/subtitles
                                                      ↓
                                              OBS Browser Source (overlay.html)
```

OBS захватывает субтитры через Browser Source — отдельную веб-страницу, которая подключается к WebSocket и показывает текст поверх стрима.

### Шаг 1: Настройка захвата аудио

Нужно направить звук из OBS в Twitch Subtitles. Проще всего — виртуальное аудиоустройство.

**Вариант A: VB-Audio Virtual Cable (рекомендуется)**

1. Скачайте и установите [VB-Audio Virtual Cable](https://vb-audio.com/Cable/) (бесплатно)
2. Перезагрузите компьютер
3. В OBS → Settings → Audio:
   - **Monitoring Device** (Устройство мониторинга): выберите `CABLE Input`
4. В OBS в микшере для нужного источника нажмите `...` → **Audio Monitoring** → **Monitor Only** (или **Monitor and Output**)
5. В Twitch Subtitles выберите источник «Микрофон», устройство — `CABLE Output`

**Вариант B: Системный микрофон**

Подходит для тестирования — просто говорите в микрофон.

### Шаг 2: Добавление Browser Source

1. Откройте OBS
2. В панели **Sources** нажмите `+` → **Browser**
3. Настройки:
   - **URL:** `http://localhost:5098/overlay.html`
   - **Width:** `1920`
   - **Height:** `1080`
4. Нажмите OK

Субтитры появятся внизу экрана поверх стрима.

### Шаг 3: Проверка

1. Запустите Twitch Subtitles (`./start.sh`)
2. На странице http://localhost:5098 выберите «Микрофон» → «Начать запись»
3. Поговорите в микрофон / воспроизведите звук
4. В OBS субтитры появятся в Browser Source через 3–5 сек (зависит от длины чанка и модели)

### Шаг 4: Настройка внешнего вида

На странице http://localhost:5098 раскройте секцию **«Оверлей для OBS»**:

| Настройка | Описание | Диапазон |
|-----------|----------|----------|
| Размер шрифта | Высота текста в пикселях | 12–48 px |
| Цвет текста | Цвет субтитров | hex (color picker) |
| Подложка | Прозрачность чёрного фона за текстом | 0–100% |
| Время показа | Через сколько субтитр исчезнет | 1–15 сек |
| Показывать перевод | Отображать английский текст под русским | вкл/выкл |

Настройки сохраняются на сервере и применяются при следующем появлении субтитра. Обновлять страницу оверлея в OBS не нужно.

### Копирование URL оверлея

В секции «Оверлей для OBS» отображается готовый URL для Browser Source. Нажмите «Копировать» и вставьте в OBS.

## Конфигурация

ML Service URL задаётся в `src/TwitchSubtitles.Web/appsettings.json`:

```json
{
  "MlService": {
    "BaseUrl": "http://127.0.0.1:8000"
  }
}
```

## Известные ограничения

- **GPU**: PyTorch не поддерживает Blackwell (RTX 5070 Ti, sm_120). Inference на CPU.
- **Latency**: ~3 сек на 3-сек чанк (CPU, модель base). На модели medium — дольше.
- **Дедупликация**: алгоритм word-level работает базово, возможны пропуски или ложные срабатывания.
