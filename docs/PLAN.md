# Twitch Subtitles - План проекта

## Обзор

Приложение для автоматических real-time субтитров с поддержкой нескольких языков для стриминговой платформы Twitch.

## Changelog

0.3.2 (запланировано): Переключение моделей перевода. ML Service: поддержка нескольких моделей (MarianMT, M2M100-418M), endpoint GET /translation-models. C# Backend: проксирование списка моделей и настройки translation_model. Frontend: dropdown для выбора модели перевода.

0.3.1 (запланировано): Улучшения UI и UX. Вывод версий сервисов в UI, progress-bar загрузки моделей, настройка вывода только перевода, встроенная инструкция по настройке OBS, скрываемый раздел "Субтитры", настройка времени скрытия и длины субтитров, кнопка очистки кэша моделей.

0.3.0 (выполнено): OBS Browser Source оверлей. Отдельная страница overlay.html подключается к WebSocket /ws/subtitles, показывает субтитры на прозрачном фоне с fade in/out. Настройки оверлея: размер шрифта, цвет, прозрачность подложки, время показа, отображение перевода. Collapsible-секция в UI с генерацией OBS URL и кнопкой копирования.

0.2.3 (выполнено): Дедупликация субтитров при включённом оверлапе (word-level, настраиваемая через UI). Багфиксы: VAD suppress short hallucinations, asyncio.to_thread для неблокирующего инференса, keep-alive WebSocket, snake_case в AppSettings.

0.2.2 (выполнено): VAD (Silero, через faster-whisper), настраиваемая длина чанка и оверлап. Единый API настроек (GET/PUT /api/settings) с персистентностью в JSON-файле. Frontend: секция настроек (модель, VAD-чекбокс, длина чанка, оверлап). Overlap buffer в аудио-захвате.

0.2.1 (выполнено): Переключение моделей Whisper через UI. Переход с openai-whisper на faster-whisper (CTranslate2, int8) — 4x ускорение на CPU. ML Service: эндпоинты GET /models, PUT /settings. C# Backend: SettingsController с проксированием. Frontend: dropdown выбора модели.

0.2.0 (выполнено): Streaming audio через WebSocket. Frontend: выбор источника (файл/микрофон), захват PCM через AudioContext, отправка чанков. Backend: WebSocket endpoint `/ws/subtitles`, `/process-chunk` в ML service. Переход на .NET 8, Swashbuckle. Захват аудио через AudioContext + ScriptProcessorNode (PCM 16-bit 16kHz → WAV).

0.1.0 (выполнено): Реализована возможность загрузки .mp3/.wav-файла, его транскрибирование и перевод с русского на английский язык.

## Принцип работы

```
Аудио OBS → STT-сервис → Переводчик → Вывод
           (Speech-to-Text)  (Translation)
```

---

## Требования

### Релизная версия

1. Все сервисы должны разворачиваться локально
2. Возможность использования сторонних API, если локальные сервисы недостаточно хороши
3. Гибкие ввод/вывод (различные источники аудио, различные назначения вывода)
4. Единый инсталлятор (без ручной установки утилит и сервисов)
5. Низкий latency для потокового режима

## Технологический стек

### Backend (C#)

| Компонент | Технология |
|-----------|------------|
| Фреймворк | ASP.NET Core 8 (Web API) |
| Хостинг | Kestrel, порт 5098 |
| Связь с ML | HttpClient |
| API Docs | Swashbuckle (Swagger) |

### ML Service (Python)

| Компонент | Технология |
|-----------|------------|
| Фреймворк | FastAPI, порт 8000 |
| STT | faster-whisper (CTranslate2, int8), выбираемая модель: tiny/base/small/medium/large |
| Перевод | MarianMT ru-en |
| Настройки | GET /models, PUT /settings (ML); GET/PUT /api/settings (C#, JSON-файл) |

### Интерфейс

| Аспект | Спецификация |
|--------|---------------|
| Ввод | REST API — загрузка .mp3, .wav; WebSocket — streaming PCM |
| Вывод | JSON — `{rus_text: "", eng_text: ""}` |

## Известные ограничения

- **GPU не работает**: RTX 5070 Ti (Blackwell, sm_120) не поддерживается PyTorch 2.12+cu126. Forced CPU через `CUDA_VISIBLE_DEVICES=""` в main.py и `device="cpu"` в stt.py. Нужно обновить PyTorch до версии с CUDA 13.x.
- **Latency**: ~3 сек на 3-сек чанк (CPU inference, модель medium, faster-whisper int8). На коротких чанках overhead вызова доминирует над инференсом — переход на faster-whisper дал минимальный прирост. Возможные оптимизации: `cpu_threads`, увеличение длины чанка до 5-6 сек.
- **Точность Whisper base**: ~90% на русской речи, мелкие ошибки в окончаниях и пунктуации.

## Примечания

- ML модели скачиваются при первом запуске (faster-whisper base ~150MB, small ~500MB, medium ~1.5GB; MarianMT ~300MB)
- Backend и ML сервис общаются через HTTP (чистое разделение, проще отлаживать)
- Тесты: pytest (Python), xUnit + Moq (C#)
- Модель STT переключается через UI без перезапуска сервисов
