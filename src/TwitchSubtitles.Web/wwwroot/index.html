Оверлей для OBS
📖 Инструкция по настройке OBS
1

Выберите способ захвата аудио

Вариант A (рекомендуется): Установите VB-Audio Virtual Cable для передачи звука из OBS.
Вариант B (проще): Используйте микрофон напрямую в Twitch Subtitles без OBS.

2A

Настройте мониторинг в OBS (для VB-Audio)

Settings → Audio → Advanced → Monitor Device → выберите "CABLE Input"

2B

Подключите микрофон (без VB-Audio)

Просто используйте свой микрофон в Twitch Subtitles — настройка OBS не требуется.

3

Добавьте Browser Source в OBS

Sources → + → Browser → Вставьте URL выше → Width/Height по размеру вашего стрима

4

Выберите устройство в Twitch Subtitles

Источник → Микрофон → Устройство: "CABLE Output" (для VB-Audio) или ваш микрофон
